# 공식 행사 자료

행사 운영자가 제공한 일정·가이드·유의사항·심사기준의 날짜별 수집본을 보관한다.
제품 기획 원본 및 팀의 실제 담당표와 구분한다.

- [2026-11-19 공식 사이트 수집 결과](2026-11-19/README.md)
- 원본: [11th Ne(o)rdinary Hackathon](https://cmc-11th-hackathon.vercel.app/)

수집본은 로컬 Git 이력으로 관리하며 GitHub 반영 여부는 별도로 확인한다.
[2026-11-21 이관 기록](../start/REPOSITORY_MIGRATION_2026-11-21.md)에서 현재 저장 상태를 확인한다.
날짜별 수집본의 상태·미검증 기록은 해당 수집 당시 기준이며 온라인 내용이 자동 동기화되지 않는다.
