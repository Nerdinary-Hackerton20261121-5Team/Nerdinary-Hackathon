# 공식 사이트 정보 수집 인계

- 작업: 2026-11-19 공식 행사 안내 사이트 브라우저 수집.
- 현재 역할: PM. 개발 기능·기술 영역 배정 없음.
- 기준: 사용자가 제공한 공식 사이트 URL, 현재 공통 지침과 PM 지침.
- 허용 범위: 공식 사이트 및 연결된 안내 자료 읽기, 로컬 수집본·출처 등록.
- 저장 상태: 로컬 변경. 이번 작업의 커밋·푸시는 수행하지 않음.

## 목표와 실제 변경

공식 사이트의 5개 메뉴 페이지, 6개 역할 × 3개 팝업, Web의 접힌 상세 배점을 확인했다.
역할별 본문, 전체 일정, 홈 정보, 수집 범위·해시 기록과 요약 문서를 docs/event에 만들었다.
프로젝트 설정에는 공식 사이트와 확인된 행사 정보를, 원본 목록에는 행사 원본을 등록했다.
제품 기획·기능·기술 스택과 참가자 배정은 이번 수집으로 확정하지 않는다.

## 검증

- 5개 주요 페이지와 18개 팝업 본문을 확보했다. 각 역할 제목과 본문이 일치함을 확인했다.
- Web 디자인 구현 상세 평가의 접힌 내용을 펼쳐 추가 수집했다.
- Google Form은 로그인 화면을 관찰했으나 내부 양식은 읽지 못했다.
- 팝업 전환 시점의 일시적인 본문 누락은 팝업 표시·닫힘 완료를 기다린 뒤 다시 수집하여 해결했다.
- 홈 장식 카드의 전환 상태는 일부 확인하지 못했다. 정보성 텍스트·메뉴·이미지 주소는 수집했다.
- PASS: 저장된 18개 팝업 본문을 브라우저 수집 데이터와 대조했고, Web의 펼친 상세 배점도 보존했다.
- PASS: 수집 원문 파일 8개의 SHA-256, 로컬 Markdown 연결, 프로젝트·원본 목록·개인 캐시 YAML 구문을 확인했다.
- PASS: .local 역할·수집 캐시의 Git 제외 규칙을 확인했다. 공유 변경은 로컬 미커밋 상태다.
- 코드 실행·연동·시연·배포 검증: N-A.
