## 심사기준

출처: [criteria — Server](https://cmc-11th-hackathon.vercel.app/criteria)

기본 총점
100점
01
인프라 및 DB 구성
30점
채점 방법

인프라 구성도와 ERD를 제출해 주세요. 이를 바탕으로 WAS와 파일 업로드 등의 구성을 살펴봐요.

인프라 구성도와 ERD를 제출하지 않으면 이 항목은 0점으로 평가해요.

세부 평가 기준

로컬 호스트 환경이면 이 항목은 0점이에요.

인프라 구성과 ERD 설계는 10점이에요.

WAS와 DB를 분리하면 5점이에요.

CI/CD 파이프라인을 구축하면 5점이에요.

기본 보안 설정은 총 10점이며, 아래 항목으로 나누어 평가해요.

민감정보를 안전하게 관리하고 외부 노출을 방지하면 3점이에요.

DB 포트를 외부에 불필요하게 노출하지 않으면 2점이에요.

HTTPS를 적용하면 2점이에요.

불필요한 서버 포트가 공개되지 않도록 방화벽·보안그룹을 설정하면 3점이에요.

인프라 구성도와 ERD는 새벽 4시까지 제출해 주세요. API를 연동할 수 있도록 이 시간까지 인프라 구성을 완료해 주세요.

인프라 구성도는 구글폼 ↗에 제출해 주세요.

폼 제출 시각이 새벽 4시 이후이면 이 항목은 0점으로 평가해요.

API 예외처리
20점
채점 방법

API 명세서와 심사자가 접근할 수 있는 배포 URL을 제공해 주세요. 제공하지 않으면 이 항목은 0점으로 평가해요.
