## 협업 도구 상태

- Design: GitHub 사용 불가. 문서·검토는 Notion, 화면·디자인 원본은 Figma를 사용한다.
- Design 외 다른 팀원: Discord·GitHub 초대 완료 — 사용자 확인.
- 초대 수락·실제 접속, Design의 Discord 상태, 팀원별 Notion·Figma 권한은 별도 확인 전이다.
- 공통 안내와 최신 내용은 [Notion 프로젝트 페이지](https://app.notion.com/p/41fc0efa070a80aeb91fe456673f9d3b)에 기록했다.
- 조회한 원본의 사본은 [WORKSPACE.md](../Plan/WORKSPACE.md)에 별도로 보관한다.

이 문서는 사용자 입력을 기록한 로컬 문서이며 Notion 담당표의 백업이 아니다.
기계 판독용 값은 [프로젝트 설정](../start/PROJECT_CONFIG.yaml)의 team 항목에 함께 기록한다.
