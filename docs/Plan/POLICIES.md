## 1. 적용 범위와 용어

앱 중심이며 웹에서도 세션을 실행한다. 개설자는 세션 생성 시 원조각을 조립 조각으로 나눌 비율을 정한다. 집중 시간이 끝나면 한 공동판에서 조립하며 방 종료 시 임시 자료를 폐기한다.

## 3. POL-001 — 서비스 범위

공부 중 딴짓을 일시적 권태로 보고, 한 활동에 머물도록 공부 화면의 방해 요소를 덜어낸다. 같은 행동이 공부인지 여부는 사용자와 상황에 따라 달라서 공부의 공통 범위를 지정하지 않는다.

## 4. POL-002 — 익명 입장과 명단 마감

개설자가 공통 목표를 정하고 기본 익명 흐름에서는 로그인 없이 시작 전에 같은 방에 들어온다. 추가 기능의 코드 입장과 랜덤 매칭에도 같은 신규 입장 마감을 적용한다. 시작 시 명단을 확정하고 신규 입장을 닫는다. 한 명은 개인, 여러 명은 공동이다.

## 5. POL-003 — 임시 식별과 권한

방 링크와 참가자 조작 권한을 구분하고, 참가자마다 임시 식별자를 쓴다. 세션 종료 시 해당 식별자로 이전 자료를 조회할 수 없게 한다. 중복 요청은 같은 참가자로 처리한다.

조립 조각은 원조각의 소유자를 그대로 따른다. 개설자를 포함한 각 참가자는 자기 조각만 옮길 수 있다. 다른 사람의 조각은 공동판에서 볼 수 있고, 타인의 이동 요청은 배치에 반영하지 않는다.

## 6. POL-004 — 고정 타이머

시작 전 개설자가 정한 공통 목표 시간이 한 번에 흐른다. 개인의 탭 전환, 무응답, 다른 참가자의 단절로 종료 예정 시각을 늦추지 않는다. 조기 종료 권한은 Q-003이다.

## 7. POL-005 — 경과 시간과 얼굴 미리보기

실제로 측정하는 시간은 방의 경과 시간이다. 앱은 카메라 권한을 받은 뒤 자기 얼굴을 실시간으로 본인에게만 띄운다. 데모는 감지 상태를 화면에서 모사한다. 얼굴 검출·시선 추적·집중 시간 분석은 이번 범위 밖이다. 웹 카메라 지원 범위와 거부 시 참여 흐름은 미정이다.

## 8. POL-006 — 시간과 개인 복원 상태

공통 타이머는 개인 복원도와 독립적으로 흐른다. 공부 중 자기 원조각의 무늬와 윤곽은 자기 복원도에 따라 드러난다. 같은 원조각을 다른 사람이 볼 때는 최대 블러로 표시하되 실제 복원 값은 보존한다. 데모의 감지 표시는 모의 상태다.

## 9. POL-007 — 연결 끊김

공부 중 연결이 끊기면 해당 참가자의 복원 상태는 당시 모습으로 고정한다. 방 시계와 다른 사람의 복원은 계속 진행한다. 단절 시각이 불명확하면 마지막으로 확인한 상태를 쓰는 안이다. 허용 지연·검출 기준은 미정이다. 탭 전환만으로 단절을 확정하지 않는다.

## 10. POL-008 — 재접속과 중복 이벤트

계정 기반 복귀는 후순위다. 방 종료 전 이탈 후 같은 계정으로 돌아오면 마지막으로 저장된 세션이 열려 있는 동안 그 방의 현재 단계로 자동 이동한다. 집중 종료 전에 복귀하면 직전 개인 기록·복원도에서 이어가고 단절 구간은 적립하지 않는다. 방의 종료 시각은 그대로다. 조립 단계에서는 현재 공동판을 표시하며 이미 자동 배치된 조각도 그대로 둔다. 복귀 요청은 중복 반영하지 않는다. 종료된 세션으로는 자동 이동하지 않는다.

## 11. POL-009 — 진행판의 타인 최대 블러와 공동 결과

집중 시간에는 자기 원조각만 복원도대로 보이며 타인 조각에는 소유자의 진행도에 관계없이 최대 블러를 덧씌운다. 공동 조립이 시작되는 순간, 타인에게만 적용했던 최대 블러를 해제한다. 이후 모든 참가자는 각 조각을 그 소유자가 집중 종료 시점까지 복원한 만큼만 본다. 집중 종료까지 복귀하지 않았으면 단절 당시 상태를, 집중 중 계정으로 복귀했으면 복귀 이후 진행분까지 포함한 상태를 사용한다. 별도의 숫자·순위 공개는 정해지지 않았다.

## 12. POL-010 — 저장하지 않는 데이터와 폐기

얼굴 미리보기는 본인 기기에서만 표시하고 영상 파일이나 전송 기록을 만들지 않는 안이다. 원본 사진·필터 적용본(채택 시)·조립 결과를 영구 보관하지 않는다. 방이 끝나면 세션 이미지, 조각과 배정, 분할 설정, 공동판 배치와 결과, 임시 식별자를 폐기한다. 세션 복귀에 쓰는 계정·참가자 연결과 임시 진행 기록도 방 종료 시 폐기한다. 계정 정보의 보관·탈퇴 정책은 POL-015에서 따로 정한다. 서비스 기본 이미지 자산은 세션 자료와 구분한다.

## 13. POL-011 — 방 수명과 한도

신규 참가는 시작 전까지 허용한다. 방 종료 시 모든 세션 자료를 폐기한다. 정상 종료 때 결과를 볼 마지막 시점, 전원 단절·개설자 이탈·대기방 방치 때의 종료 기준은 정해야 한다. 최대 참가 인원과 파일 허용 형식·용량도 미정이다.

## 14. POL-012 — 본인 전용 카메라와 모의 감지

데모에서 실제 제공할 카메라 기능은 본인 얼굴을 화면에 띄우는 미리보기다. 집중 감지 표시는 시연용 모의 상태로 정의한다. 기능명세와 시연 설명에서 이 범위를 명시한다. 다른 참가자의 화면이나 결과 이미지에는 얼굴이 포함되지 않는다.

## 15. POL-013 — 세션 이미지와 원조각별 재분할

개설자가 세션을 만들 때 조립 조각의 분할 비율을 정한다. 집중이 끝나면 그 설정을 원조각에 적용한다. 1/4이면 원조각 하나에서 네 조각이 생기며, 원조각 6개에 같은 설정을 적용하면 총 24개다. 1/4 외에 제공할 비율 선택지는 미정이다.

세션을 열기 전에 개설자가 선택한 이미지에 필터를 적용하는 기능을 검토한다. 채택한다면 확정한 이미지를 분할과 완성 그림의 기준으로 삼는 안이다. 필터 종류와 필수 구현 여부는 미정이다.

## 16. POL-014 — 조립 조각과 공동 퍼즐판

공동 조립 시작 시 모든 참가자가 소유자별 최종 복원 모습과 같은 판을 본다. 각자 자기 조립 조각만 옮긴다. 팀 통과 조건은 배정된 모든 조립 조각이 각각의 원래 위치에 놓이는 것이다. 미배치 또는 오배치가 하나라도 있으면 조립을 계속한다. 복원도와 개인별로 맞힌 개수는 통과 조건에 쓰지 않는다.

집중 종료 시 시작 명단의 참가자가 접속해 있지 않으면 그 사람에게 배정될 조립 조각 전부를 시스템이 정답 위치에 자동 배치한다. 계정 유무와 무관하다. 집중 종료 전에 복귀해 접속 중인 사람은 직접 조립한다. 자동 완성은 조각의 위치에 적용하며 그림은 마지막 복원 상태를 유지한다. 자동 배치된 조각도 팀 통과 판정에 포함된다.

소유자가 자기 조각을 틀린 칸에 놓으면 그 조각만 드래그를 시작한 위치로 돌아간다. 대기 중이던 조각은 대기 영역의 원래 자리로, 판 위에서 옮기던 조각은 직전 칸으로 돌아간다. 잘못 놓은 칸은 점유하지 않으며 다른 조각의 배치는 그대로다. 소유자는 돌아온 조각을 즉시 다시 놓을 수 있다.

## 17. POL-015 — 계정과 닉네임

계정 가입·로그인·닉네임·계정 관리 및 계정 복귀는 모두 후순위다. 계정은 이메일 또는 아이디와 비밀번호로 인증하며 닉네임을 사용한다. 코드 입장과 랜덤 매칭에는 로그인이 필요 없다. 가입 시 받을 식별자, 닉네임 중복, 비밀번호 재설정과 계정 탈퇴·보관 기준은 미정이다. 방 종료 후 사진과 결과를 폐기하는 POL-010은 계정 참가에도 적용한다.

## 18. POL-016 — 세션 코드 입장과 랜덤 매칭

비회원도 ‘방 찾기’에서 코드를 입력해 해당 대기방에 입장하거나 코드 없이 랜덤 매칭을 요청할 수 있다. 개설자는 ‘랜덤 참가 허용’ 여부를 정한다. 랜덤 매칭은 이를 켠 기존 대기방 중 빈자리가 있는 곳에 무작위로 배정한다. 랜덤 허용 여부가 유일한 매칭 조건이고, 시작 전·빈자리 확인은 공통 입장 규칙이다. 허용을 끈 방도 코드 입장은 가능하다. 정원 수치, 대기·취소 안내, 코드 유효기간은 미정이다.

## 19. 변경 기록

v0.11에서 계정 기능을 후순위로 정하고 비회원 입장·랜덤 허용 조건, 같은 계정의 마지막 세션 자동 복귀, 집중 종료 시 부재자의 조각 자동 배치를 반영했다.

v0.10에서 계정·입장·매칭 정책을 추가하고, 계정 참가자가 복귀하면 단절 구간을 건너뛰고 마지막 기록에서 이어가도록 POL-008을 개정했다.

v0.9에서 오배치한 조각만 직전 위치로 돌려보내고 소유자가 즉시 다시 놓을 수 있도록 확정했다.

v0.8에서 자기 조각만 이동하고 모든 조각이 제자리에 있으면 팀이 통과하는 정책을 확정했다. 오배치 시 화면 동작은 검토 대상으로 남겼다.

v0.7에서 개설자가 방을 만들 때 분할 비율을 정하고, 조립 시작 시 타인용 최대 블러를 풀어 각 소유자의 최종 복원 상태를 공유하기로 확정했다.

v0.6에서 세션 생성 시 필터 후보, 참여자별로 다른 진행 화면, 원조각별 재분할, 공동판 조립안을 반영했다.

v0.5에서 본인 얼굴 미리보기와 모의 감지로 데모 범위를 정리하고 전체 세트 배부·개인판과 개인별 조립 결과를 반영했다.

v0.4에서 앱 중심·웹 실행, 본인 전용 얼굴 촬영, 코드 기반 퍼즐 분할, 전체판 공개와 타이머 뒤 위치 판정을 반영했다.

v0.3에서 고정 타이머, 시작 명단, 단절 시 고정, 직접 분할과 복원 방향, 종료 시 폐기를 반영했다.

v0.2에서 개설자 이미지 등록과 인원별 분할, 목표 시간 대비 부위 성장, 개인 전체 이미지와 최종 합성 정책을 추가했다.
