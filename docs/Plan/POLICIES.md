## 1. 적용 범위와 용어

앱이 주 이용 환경이고 웹에서도 세션을 실행한다. 방의 고정 타이머, 참가자별 퍼즐 복원도, 게임의 정답·오답은 각각 다른 상태다. 타이머 만료 시 조각의 복원을 마감한 뒤 위치를 맞히고, 방 종료 시 임시 자료를 폐기한다.

## 3. POL-001 — 서비스 범위

공부 중 딴짓을 일시적 권태로 보고, 한 활동에 머물도록 공부 화면의 방해 요소를 덜어낸다. 같은 행동이 공부인지 여부는 사용자와 상황에 따라 달라서 공부의 공통 범위를 지정하지 않는다.

## 4. POL-002 — 익명 입장과 명단 마감

개설자가 공통 목표를 정하고 참가자는 로그인 없이 시작 전에 같은 방에 들어온다. 시작 시 명단을 확정하고 신규 입장을 닫는다. 한 명은 개인, 여러 명은 공동이다.

## 5. POL-003 — 임시 식별과 권한

방 링크와 참가자 조작 권한을 구분하고, 참가자마다 임시 식별자를 쓴다. 세션 종료 시 해당 식별자로 이전 자료를 조회할 수 없게 한다. 중복 요청은 같은 참가자로 처리한다.

## 6. POL-004 — 고정 타이머

시작 전 개설자가 정한 공통 목표 시간이 한 번에 흐른다. 개인의 탭 전환, 무응답, 다른 참가자의 단절로 종료 예정 시각을 늦추지 않는다. 조기 종료 권한은 Q-003이다.

## 7. POL-005 — 경과 시간과 앱 카메라

공통 타이머는 경과 시간을 측정한다. 앱에서는 카메라로 얼굴을 촬영해 본인만 볼 수 있게 한다. 공부의 범위와 실제 집중 여부를 탭의 표시 상태나 얼굴 하나로 확정하지 않는다. 외부 앱·사이트 사용 내역은 수집 대상에서 제외한다. 웹에서도 세션을 열 수 있으며 웹에서 촬영까지 지원할지는 미정이다.

## 8. POL-006 — 시간과 개인 복원 상태

고정 타이머는 개인의 카메라 상태와 독립적으로 흐른다. 각 조각은 복원도가 높아질수록 원본을 더 많이 보여준다. 얼굴 검출 여부 등 어떤 신호를 얼마만큼 반영할지는 미정이다. 카메라 미검출·권한 거부를 세션 단절과 같은 사건으로 처리하지 않는다.

## 9. POL-007 — 연결 끊김

연결이 끊기면 그 참가자의 조각은 당시 모양으로 고정한다. 방 시계와 다른 조각은 계속 진행한다. 통신 지연 때문에 단절 시각이 불명확하면 마지막으로 확인한 상태를 쓰는 안이다. 허용 지연·검출 기준은 미정이다. 탭 전환만으로 단절을 확정하지 않는다.

## 10. POL-008 — 재접속과 중복 이벤트

고정된 조각은 그 회차의 최종 합성까지 그대로 둔다. 재접속 요청을 신규 입장이나 누락 시간 적립으로 처리하지 않는다. 기존 참가자에게 보기만 허용할지는 검토한다. 중복 이벤트는 한 번만 적용한다.

## 11. POL-009 — 진행판과 게임 결과

공부 중에는 방 참가자들이 전체 퍼즐과 각자 맡은 조각의 복원 상태를 확인한다. 얼굴 영상은 촬영한 본인에게만 표시한다. 타이머가 끝나면 복원된 조각의 위치를 고르게 하고 정답·오답을 구분한다. 이는 게임의 결과다. 이름 노출·점수·재시도·제한시간은 미정이다.

## 12. POL-010 — 저장하지 않는 데이터와 폐기

업로드 사진과 게임 결과를 영구 저장하지 않는다. 방 종료 시 사진, 퍼즐 조각·정답 위치, 명단, 복원도, 선택·판정 이력과 임시 식별자를 폐기한다. 본인 전용 얼굴 촬영은 기기 내 실시간 미리보기로 구현하고 영상 파일·서버 전송·로그 기록을 만들지 않는 안을 제안한다. 카메라를 끄거나 공부 단계가 끝나면 영상 입력을 종료하는 안이다. 서비스의 기본 이미지 자산은 세션 자료와 구분한다.

## 13. POL-011 — 방 수명과 한도

신규 참가는 시작 전까지 허용한다. 방 종료 시 모든 세션 자료를 폐기한다. 정상 종료 때 결과를 볼 마지막 시점, 전원 단절·개설자 이탈·대기방 방치 때의 종료 기준은 정해야 한다. 최대 참가 인원과 파일 허용 형식·용량도 미정이다.

## 14. POL-012 — 카메라 공개 범위와 집중 확인

팀 논의로 정한 것은 앱에서 카메라로 얼굴을 촬영해 본인에게만 보여주는 방식이다. 다른 참가자의 기기·공동 진행판·게임 결과에 얼굴이 노출되지 않아야 한다. 허용 요청, 권한 거부·카메라 미지원·얼굴 미검출 안내를 구분하는 안이다. 종이책을 보며 고개를 숙인 상태도 있으므로 구체적 판정·복원 산식과 검증은 Q-008로 남긴다.

## 15. POL-013 — 퍼즐 자동 분할과 자리 배정

기본 이미지를 쓰거나 개설자가 업로드한 한 장을 쓴다. 공동 세션에서는 시작 인원수에 맞춰 프로그램이 맞물리는 퍼즐 조각을 자동 생성·배정한다. 각 조각의 모양과 정답 위치를 게임 판정까지 유지한다. 1인 전체 이미지를 위치 맞히기로 연결하는 규칙은 미정이다.

## 16. POL-014 — 퍼즐 복원과 위치 맞히기

절단면부터 자기 영역 안에서 복원하고 가능하면 가장자리를 불규칙하게 표현한다. 공부 중에는 전체판과 모든 조각의 복원 상태를 보여준다. 만료 순간의 조각을 게임으로 넘겨 복원된 만큼만 무늬와 윤곽을 볼 수 있게 한다. 고른 자리가 원래 위치와 일치하면 정답, 다르면 오답이다. 진행판이 정답표가 되지 않도록 진행판에는 조각을 참가자별로 모아 두고 게임에서 빈 판의 자리를 고르는 방식을 제안한다. 판의 배치·재시도·개인 모드의 후보 수는 미정이다.

## 17. 변경 기록

v0.4에서 앱 중심·웹 실행, 본인 전용 얼굴 촬영, 코드 기반 퍼즐 분할, 전체판 공개와 타이머 뒤 위치 판정을 반영했다.

v0.3에서 고정 타이머, 시작 명단, 단절 시 고정, 직접 분할과 복원 방향, 종료 시 폐기를 반영했다.

v0.2에서 개설자 이미지 등록과 인원별 분할, 목표 시간 대비 부위 성장, 개인 전체 이미지와 최종 합성 정책을 추가했다.
