**Design은 GitHub를 사용할 수 없다.** Design에게 필요한 기획·결정·화면 설명·검토 내용은 Notion에 기록하고, 디자인 원본과 인계 대상 프레임은 Figma에서 연결한다. GitHub에서 발생한 Design 관련 변경도 Notion에서 확인할 수 있도록 요약한다.

| 대상 | GitHub | Discord |
| --- | --- | --- |
| Design | 사용 불가 — 사용자 확인 | 초대·접속 상태 별도 확인 전 |
| Design 외 다른 팀원 | 초대 완료 — 사용자 확인 | 초대 완료 — 사용자 확인 |

위 상태는 초대 여부에 대한 사용자 확인이다. 초대 수락·실제 접속과 팀원별 Notion·Figma 권한은 확인되지 않았다.

### 변경 전달 기준

- 기획·정책·배정·결정의 현재 기준은 Notion에 남긴다.
- 화면·디자인의 현재 기준은 Figma에 남기고 관련 Notion 설명과 연결한다.
- 변경을 전달할 때 바뀐 내용, 영향을 받는 화면·기능, 관련 링크, 확인이 필요한 항목을 함께 적는다.
- Discord에서 결정한 내용은 관련 Notion 문서에 반영한다.
- 온라인 수정은 AI나 GitHub 사본에 자동 반영되지 않는다. 작업 시작·변경 전달·통합 시 필요한 범위를 다시 확인한다.

## 해커톤 주제와 팀 선택

**권태:** 선택지가 너무 많아 하나의 경험에 깊이 빠져들지 못하고, 끊임없이 다음 자극을 찾아 나서는 상태.

**서비스 지향점:** 권태를 자극으로 덮지 않고, 하나에 깊이 빠져들게 만드는 서비스.

| 항목 | 확인 내용 |
| --- | --- |
| 주제 조합 | **권태 + 공부 × 덜어내기** |
| 장면 카드 | 공부 — 장면은 추첨 |
| 공부의 장면 예시 | 수업, 시험기간, 독서, 자격증, 팀플 |
| 처방 카드 | 덜어내기 — 처방은 팀이 선택 |
| 덜어내기의 설명 | **기능을 빼서 단순하게 만듦** |
| 주제 변경 마감 | 2026-11-21 16:20 (Asia/Seoul) 이후 변경 불가 — 사용자 전달 |

팀의 카드 선택은 확인했다. 운영진 제출·접수 여부는 별도 확인 전이다. 권태의 정의·서비스 지향점·변경 마감·팀 선택은 사용자 메시지에 근거하며, 카드별 설명과 예시는 제공된 S15\~S18 슬라이드에 근거한다.

### 장면·처방 카드 전체와 참고 예시

조합 방식은 **권태 + 장면 × 처방**이다. 장면은 권태를 느끼는 일상의 장면을 추첨하고, 처방은 그 권태를 깨는 방식을 팀이 선택한다.

장면 카드 8장 — S16

| 장면 | 예시 |
| --- | --- |
| 연애 | 썸, 오래된 커플, 데이트, 연락 |
| 우정 | 오래된 친구, 단톡방, 약속 잡기, 생일 |
| 가족 | 부모님과 대화, 형제, 명절, 가족 식사 |
| 이동 | 통학, 출퇴근, 대중교통, 걷기, 운전 |
| 공부 | 수업, 시험기간, 독서, 자격증, 팀플 |
| 일 | 출근, 알바, 회의, 반복 업무 |
| 집 | 자취, 집안일, 내 방, 룸메이트 |
| 콘텐츠 | 영상, 음악, 웹툰, 피드, 볼 거 고르기 |

처방 카드 10장 — S17

| 처방 | 설명 |
| --- | --- |
| 우연 | 예측 못 한 것을 만나게 함 |
| 제약 | 선택지를 일부러 줄임 |
| 느림 | 빨리 못 넘기게 함 |
| 함께 | 혼자 하던 걸 같이 하게 함 |
| 몰입 | 하나에 오래 머물게 함 |
| 낯설게 | 익숙한 걸 다른 시선으로 보게 함 |
| 역할 바꾸기 | 소비하던 사람이 만드는 사람이 됨 |
| 손맛 | 손으로 직접 해야 함 |
| 덜어내기 | 기능을 빼서 단순하게 만듦 |
| 사라짐 | 일정 시간이 지나면 없어짐 |

주최 측 슬라이드의 참고 예시 — S15·S18

| 조합 | 예시 |
| --- | --- |
| 이동 × 제약 | 하루에 노래 3곡만 고를 수 있는 통학 플레이리스트 |
| 연애 × 느림 | 보낸 메시지가 3일 뒤에 도착하는 느린 편지 |
| 콘텐츠 × 덜어내기 | 볼 작품 하나를 고르면 다른 추천이 전부 숨겨지는 서비스 |

슬라이드는 예시가 참고용이며 정답이 아니라고 안내한다. 위 예시는 우리 팀이 채택한 제품 아이디어가 아니다.

## 현재 MVP와 작성 문서

개설자가 공통 목표 시간을 정하고 같은 방에서 혼자 또는 여럿이 시작한다. 시작 전 인원으로 명단을 닫고 고정 타이머를 진행한다. 연결이 끊긴 참가자의 조각은 당시 모습으로 고정한다.

- [집중 세션 MVP — v0.4](https://app.notion.com/p/41fc0efa070a81cab233c8bd5de5282d)
- [집중 세션 기능명세 — v0.4](https://app.notion.com/p/41fc0efa070a812e9017ee2892491213)
- [집중 세션 정책서 — v0.4](https://app.notion.com/p/41fc0efa070a816ba3a0c1719aa63984)

기본 이미지 또는 업로드한 사진을 코드로 퍼즐처럼 나눈다. 공부 중 전체 퍼즐과 내 조각·팀원 조각의 복원 상태가 보인다. 앱 카메라로 촬영한 얼굴은 본인에게만 보인다.

타이머가 끝나면 그 시점까지 복원된 조각이 들어갈 자리를 맞힌다. 복원도가 높을수록 이미지 단서가 많이 보이고, 위치 선택 후 정답·오답을 확인한다. 방 종료 시 사진·결과와 임시 자료를 폐기한다. 카메라 신호를 복원도에 연결하는 기준, 웹 촬영 범위, 1인 게임·재시도 규칙은 미정이다.
