## 6. F-004 — 경과 시간·얼굴 미리보기·모의 감지

앱 카메라 권한을 허용하면 집중 화면 좌상단에서 자기 얼굴을 실시간으로 볼 수 있다. 감지 상태는 시연용으로 모사하고, 기능 설명에서는 데모 표시로 구분한다. 실제 얼굴 검출기·시선 추적기·집중 점수는 이번 데모의 전제에 포함하지 않는다. 권한을 거절했을 때의 안내와 웹 카메라 범위는 미정이다.

완료 기준 초안

- AC-011 목표 20분에 시작 후 8분이면 경과 8분·남은 시간 12분이다.
- AC-012 앱 또는 탭을 바꿔도 같은 방의 경과 시간 계산식을 쓴다.
- AC-013 종이책을 읽거나 우리 화면에서 손을 떼도 실패·딴짓으로 표시하지 않는다.
- AC-014 음수 남은 시간이나 목표를 넘는 타이머 진행률은 표시하지 않는다.
- AC-033 두 참가자가 각자의 앱 카메라를 켜도 상대 화면이나 공동 퍼즐판에 다른 사람의 얼굴이 나타나지 않는다.
- AC-034 얼굴 미리보기와 모의 감지 상태를 별도로 확인할 수 있다. 카메라를 꺼도 공통 타이머가 멈추지 않고 실제 집중 측정값이 생성되지 않는다.

### 추가 메모 · 프론트엔드 구현 현황 (2026년 11월 22일)

프론트엔드 `dev`의 카메라 확인 화면(`/#/camera-test`)에서는 MediaPipe로 영상을 기기 안에서 처리해 **자리에 있음**(`present`), **다른 곳을 봄**(`looking-away`), **자리 비움**(`absent`)을 구분한다. 책을 읽으려고 고개를 숙인 경우에는 얼굴이 잘 보이지 않아도 몸의 단서를 이용해 재실 여부를 판단한다. [판정 코드](https://github.com/Nerdinary-Hackerton20261121-5Team/Frontend/blob/c3e83f49187b7bb62dfb258e53d437f2f34593c6/src/features/attention/attention.ts#L295-L357) · [카메라 확인 화면](https://github.com/Nerdinary-Hackerton20261121-5Team/Frontend/blob/c3e83f49187b7bb62dfb258e53d437f2f34593c6/src/features/attention/CameraTestPage.tsx#L25-L43)

확인 범위는 해당 화면과 판정 로직의 소스 코드다. 실기기별 정확도와 공부 세션에서의 퍼즐 복원 연동은 별도 검증 항목이다. 카메라의 ‘자리 비움’은 화면에서 관찰한 상태이고, 세션의 연결 여부는 별도로 판단한다.
