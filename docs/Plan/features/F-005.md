## 7. F-005 — 연결 끊김·조각 고정

방의 시계와 조각 상태를 따로 관리한다. 연결이 끊긴 참가자의 조각은 단절 당시의 상태로 그 회차 동안 고정한다. 끊김 검출이 늦을 수 있어 마지막으로 확인한 표시 상태를 기준으로 삼는 안을 제안한다.

완료 기준 초안

- AC-015 같은 끊김 통지를 다시 받아도 고정된 조각이 바뀌지 않는다.
- AC-016 끊김 뒤 시간이 더 흘러도 고정된 조각은 그 상태로 합성된다.
- AC-017 단절 원인을 집중 중단으로 표시하지 않는다.
- AC-018 같은 참가자가 재접속하거나 두 탭을 열어도 새 조각을 배정하거나 고정된 조각을 더 키우지 않는다.
- AC-019 기기 시계 변경이나 뒤늦은 이벤트로 이미 고정한 모양을 덮어쓰지 않는다.
