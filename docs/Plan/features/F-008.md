## 10. F-008 — 인원별 퍼즐 사전 분할·배정

시작 명단 기준으로 기본 이미지나 업로드 사진을 미리 분할한 뒤 참가자당 2\~3개씩 배정한다. 4명은 총 12조각을 3개씩, 5명은 총 10조각을 2개씩, 6명은 총 12조각을 2개씩 맡는다. 집중과 공동 조립에 동일한 조각을 사용한다. 4\~6명 이외의 인원별 총수는 미정이다.

완료 기준 초안

- AC-026 기본 이미지도 시작 인원에 맞춰 미리 분할하고 조각마다 한 명의 소유자와 정답 칸을 정한다.
- AC-027 업로드 실패 시 파일을 다시 선택하거나 기본 이미지로 진행할 수 있다. 정상 사진은 분할선 입력 없이 퍼즐로 나뉜다.
- AC-028 4명·5명·6명 방에서 전체 조각 수가 각각 12·10·12이고, 각 참가자가 각각 3·2·2개씩 갖는다. 한 조각도 중복 배정되거나 빠지지 않는다.
