## 10. F-008 — 퍼즐 이미지 자동 분할·배정

기본 이미지를 선택하거나 개설자가 사진 한 장을 올린다. 공동 세션에서는 시작 인원수에 맞춰 코드가 맞물리는 퍼즐 조각을 생성·배정한다. 생성 때 각 조각의 원래 위치를 회차 동안 유지해 마지막 판정에 사용한다.

완료 기준 초안

- AC-026 업로드 없이 기본 이미지로 시작할 수 있고 각 참가자는 자신의 조각을 확인한다.
- AC-027 업로드 실패 시 파일을 다시 선택하거나 기본 이미지로 진행할 수 있다. 정상 사진은 분할선 입력 없이 퍼즐로 나뉜다.
- AC-028 N명의 공동 세션에서 N개 조각이 한 명당 하나씩 배정되고, 정답 위치에 모두 놓으면 겹침이나 누락 없이 같은 원본을 이룬다.
