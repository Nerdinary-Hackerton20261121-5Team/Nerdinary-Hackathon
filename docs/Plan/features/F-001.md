## 3. F-001 — 공동 세션 개설·초대

개설자는 세션을 만들 때 공통 목표 시간과 이미지를 정하고 랜덤 참가 허용 여부를 선택한다. 시작 전까지 초대 링크나 세션 코드를 공유할 수 있다. 1인과 여러 명이 같은 입구를 쓴다. 검토 중인 선택 기능은 방 개설 전 이미지에 필터를 적용하고 미리본 모습으로 세션을 여는 것이다. 채택 시 같은 변형 이미지를 분할·복원·조립에 사용한다.

완료 기준 초안

- AC-001 방 생성 후 시작 전에는 다른 기기에서 링크로 입장할 수 있다.
- AC-039 시작 명단이 5명이면 10조각을 미리 만들고 각자 2개씩 배정한다. 조립 시작 후에도 조각 수와 소유자가 같다.
- AC-002 생성 요청을 재전송해도 방이 중복 생성되지 않는다.
- AC-003 생성 취소·실패는 타이머를 시작하지 않는다.
