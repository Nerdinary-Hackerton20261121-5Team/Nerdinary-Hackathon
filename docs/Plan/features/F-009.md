## 11. F-009 — 진행판의 개인 복원·타인 최대 블러

집중 중에는 내 조각은 개인 복원도대로 보인다. 다른 사람의 조각은 화면에 무작위로 배치하고 최대 블러를 덧씌운다. 공동 조립 시작 시 그 덧씌운 블러를 제거한다. 조립 조각마다 집중 종료 시점에 소유자가 복원한 영역만 전원에게 동일하게 보인다. 집중 종료까지 돌아오지 않은 참가자의 조각에는 단절 당시의 복원 상태를 사용한다. 집중 중 계정으로 복귀했다면 복귀 후 진행분을 포함한 최종 상태를 사용한다.

완료 기준 초안

- AC-029 집중 시간에는 내 조각이 내 복원도에 맞춰 무늬와 윤곽이 드러난다. 동일한 조각을 다른 참가자가 보았을 때에는 집중 시간이 끝날 때까지 최대 블러다.
- AC-030 집중 시간에 자기 조각은 이웃과 맞닿는 절단면부터 복원되고 100%에서 해당 원본 영역과 일치한다. 같은 시점에도 팀원 화면에서는 이 조각의 최대 블러가 유지된다.
- AC-031 한 사람의 연결이 끊기면 성장 경계도 고정된다. 다른 사람의 조각은 계속 진행한다.
- AC-032 같은 세션의 동일한 진행 상태를 다시 그릴 때 불규칙 경계도 튀거나 후퇴하지 않는다. 세션 종료 시 합성 결과를 폐기한다.
- AC-037 A의 복원 상태를 낮은 단계에서 높은 단계로 바꾸면 A 화면만 해당 변화가 보이고 B 화면의 A 조각은 두 시점 모두 최대 블러다. B 조각은 반대로 검증한다.
- AC-040 A가 30%, B가 80%에서 집중을 마치면 공동 조립 첫 화면부터 모든 기기가 각각 A의 30%, B의 80% 상태를 사용한다. 좌우 배치나 조각 이동으로 미복원 영역이 추가 공개되지 않는다.
- AC-038 웹에서 진행판을 보고 만료 후 자기 조립 조각과 방의 공동판으로 진입하는 경로를 검증한다. 웹 카메라 지원은 별도 검토 대상이다.
- AC-057 집중 중 내 카메라 미리보기는 좌상단에 있고 타인 조각은 무작위 위치에서 최대 블러로 보인다. 화면 배치가 달라도 소유자와 복원 상태는 같다.
