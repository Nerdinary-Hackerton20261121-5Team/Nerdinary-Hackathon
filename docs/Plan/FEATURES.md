## 2. 논리 입력·출력

방은 개설자가 세션 생성 시 정한 분할 비율, 세션 이미지와 원조각별 소유자·복원 상태를 관리한다. 조립 조각마다 원조각과 원래 좌표를 유지한다. 조립 시작 때 소유자별 최종 복원 상태를 확정하고, 모든 참가자가 같은 조각 모습과 같은 공동판 배치를 보게 한다. 조립 조각의 이동 권한은 그 원조각을 배정받은 참가자에게 있다. 판의 통과 상태는 방에 속한 전체 조립 조각의 현재 위치로 판단한다.

## 3. F-001 — 공동 세션 개설·초대

개설자는 세션을 만들 때 공통 목표 시간과 조립용 분할 비율을 정하고 랜덤 참가 허용 여부를 선택한다. 시작 전까지 초대 링크나 세션 코드를 공유할 수 있다. 1인과 여러 명이 같은 입구를 쓴다. 검토 중인 선택 기능은 방 개설 전 이미지에 필터를 적용하고 미리본 모습으로 세션을 여는 것이다. 채택 시 같은 변형 이미지를 분할·복원·조립에 사용한다.

완료 기준 초안

- AC-001 방 생성 후 시작 전에는 다른 기기에서 링크로 입장할 수 있다.
- AC-039 개설자가 세션 생성 시 1/4를 선택하면 만료 뒤 해당 원조각 한 개에서 조립 조각 4개가 나온다. 참가자 입장·조립 화면에서 비율을 다시 입력하지 않는다.
- AC-002 생성 요청을 재전송해도 방이 중복 생성되지 않는다.
- AC-003 생성 취소·실패는 타이머를 시작하지 않는다.

## 4. F-002 — 익명 참가·시작 명단 확정

로그인 없이 세션 안에서만 유효한 식별자로 참가한다. 시작 시점의 입장 승인 명단으로 참가 명단을 고정한다. 시작과 신규 입장이 겹치면 확정 명단을 기준으로 응답한다. 이 절은 기본 익명 입장에 적용한다. 계정 가입과 코드·랜덤 입장, 기존 참가자 복귀는 F-010\~F-013에 정의한다.

완료 기준 초안

- AC-004 같은 방에서도 A와 B의 임시 식별·원조각 소유 관계·개인 복원 상태를 구분한다.
- AC-005 시작 후 신규 입장 및 만료 링크 입장을 거절하고 기존 참가자의 원조각 배정과 방 상태를 유지한다.
- AC-006 공유 링크나 다른 참가자 식별자만으로 타인의 복원 상태를 변경하거나 타인 소유의 조립 조각을 옮길 수 없다.

## 5. F-003 — 고정 타이머 시작·만료

개설자의 시작으로 모든 참가자가 같은 시작·목표 종료 시점을 사용한다. 타이머는 화면 전환, 무응답, 특정 참가자의 이탈 중에도 정해진 속도로 흐른다.

완료 기준 초안

- AC-007 방 개설과 실제 타이머 시작을 구분한다.
- AC-008 화면을 떠나거나 쉬어도 방의 종료 예정 시각은 그대로다.
- AC-009 참가자 A의 단절은 참가자 B의 타이머 진행을 바꾸지 않는다.
- AC-010 시작·만료가 중복 전달돼도 원래 시작·종료 기준을 한 번만 적용한다.

## 6. F-004 — 경과 시간·얼굴 미리보기·모의 감지

앱 카메라 권한을 허용하면 자기 얼굴을 실시간으로 볼 수 있다. 감지 상태는 시연용으로 모사하고, 기능 설명에서는 데모 표시로 구분한다. 실제 얼굴 검출기·시선 추적기·집중 점수는 이번 데모의 전제에 포함하지 않는다. 권한을 거절했을 때의 안내와 웹 카메라 범위는 미정이다.

완료 기준 초안

- AC-011 목표 20분에 시작 후 8분이면 경과 8분·남은 시간 12분이다.
- AC-012 앱 또는 탭을 바꿔도 같은 방의 경과 시간 계산식을 쓴다.
- AC-013 종이책을 읽거나 우리 화면에서 손을 떼도 실패·딴짓으로 표시하지 않는다.
- AC-014 음수 남은 시간이나 목표를 넘는 타이머 진행률은 표시하지 않는다.
- AC-033 두 참가자가 각자의 앱 카메라를 켜도 상대 화면이나 공동 퍼즐판에 다른 사람의 얼굴이 나타나지 않는다.
- AC-034 얼굴 미리보기와 모의 감지 상태를 별도로 확인할 수 있다. 카메라를 꺼도 공통 타이머가 멈추지 않고 실제 집중 측정값이 생성되지 않는다.

## 7. F-005 — 연결 끊김·개인 복원 상태 고정

방의 시계와 개인별 복원 상태를 따로 관리한다. 공부 중 연결이 끊기면 그 사람의 복원 상태는 당시 모습으로 고정한다. 끊긴 시점이 불명확하면 마지막으로 확인한 표시 상태를 쓰는 안이다. 계정으로 집중 중 복귀하면 F-013에 따라 복귀한 시점부터 남은 구간의 기록을 이어간다.

완료 기준 초안

- AC-015 같은 끊김 통지를 다시 받아도 고정된 조각이 바뀌지 않는다.
- AC-016 연결이 끊겨 있는 동안 방의 시간이 더 흘러도 해당 참가자의 고정된 복원 상태는 덮어쓰지 않는다.
- AC-017 단절 원인을 집중 중단으로 표시하지 않는다.
- AC-018 같은 사람이 두 탭을 열거나 재접속해도 조립 조각이나 공동판이 중복 생성되지 않고 단절 시점의 개인 복원 상태가 임의로 증가하지 않는다.
- AC-019 기기 시계 변경이나 뒤늦은 이벤트로 이미 고정한 모양을 덮어쓰지 않는다.

## 8. F-006 — 공동 퍼즐판 조립·종료 폐기

모두 같은 공동판을 보고 각자 자기 원조각에서 나뉜 조립 조각만 옮긴다. 배치 요청을 받으면 해당 회차의 참가자와 조각 소유자를 대조한다. 타인 조각의 이동은 공동판에 반영하지 않는다. 승인된 배치는 참가자 모두에게 같은 자리에 표시한다. 아직 놓지 않았거나 위치가 틀린 조각이 하나라도 있으면 조립 중이다. 전체 조각이 각자의 정답 위치에 놓이는 순간 팀 통과를 표시한다. 자기 조각을 틀린 칸에 놓으면 해당 배치를 반영하지 않고 그 조각만 드래그 직전 위치로 되돌린다. 소유자는 즉시 같은 조각을 다시 놓을 수 있다.

집중 종료 시 시작 명단에 있으면서 접속해 있지 않은 참가자를 확인한다. 공동 조립을 열 때 그 사람 몫의 조각 전부를 정답 칸에 자동 배치한다. 이 처리는 로그인 여부와 무관하며, 개인 기록과 그림의 선명도는 마지막 복원 상태 그대로다. 자동 배치분도 전체 정답 판정에 포함한다.

완료 기준 초안

- AC-020 같은 회차가 끝나면 이전 링크로 사진·결과 또는 시간 기록을 다시 조회할 수 없다.
- AC-021 결과는 해당 세션 범위에서만 열 수 있다.
- AC-022 시간 표시는 경과 시간으로 읽을 수 있고 집중 인증 점수를 붙이지 않는다.
- AC-023 응답 누락이나 단절만으로 사용자에게 실패 판정을 표시하지 않는다.
- AC-035 공동 조립에서 A와 B가 서로 다른 조각을 놓으면 두 기기 모두 같은 두 배치를 표시한다. 정답 위치는 해당 조각의 원본 좌표로 구분한다.
- AC-036 재전송이나 동시 입력 뒤에도 같은 조각이 두 자리에 남지 않고 참가자 화면의 공동 결과가 일치한다.
- AC-041 A가 자기 조각을 옮기면 모든 기기에 같은 배치가 보인다. B의 조각을 옮기려는 입력이나 요청은 공동판을 바꾸지 않는다. 같은 규칙이 개설자에게도 적용된다.
- AC-042 마지막 한 조각을 틀린 칸에 놓으면 그 칸을 점유하지 않고 모든 화면에서 조립 중으로 남는다. 소유자가 같은 조각을 정답 칸에 다시 놓아 전체가 맞으면 팀이 통과한다.
- AC-043 마지막 조각이 제자리에 놓여 전체가 맞으면 모든 참가자에게 팀 통과가 표시된다. 원조각이 일부만 복원되었어도 위치가 전부 맞으면 통과하며, 마지막 배치가 재전송되어도 통과 처리는 한 번이다.
- AC-044 A가 대기 영역에서 자기 조각을 B의 조각이 놓인 칸에 놓으면 A의 조각만 대기 영역의 직전 자리로 돌아간다. 두 사람의 화면에서 B의 조각은 그대로이고 A는 즉시 다시 시도할 수 있다.
- AC-045 판 위에서 옮기던 자기 조각을 틀린 칸에 놓으면 그 조각은 드래그 직전 칸으로 돌아간다. 동시에 팀원이 다른 조각을 올바르게 놓았다면 두 화면에 그 배치도 그대로 보인다.
- AC-053 A가 집중 종료 전에 돌아오지 않고 B가 접속 중이면, 공동판을 열 때 A 몫은 모두 정답 칸에 있고 B 몫은 B가 직접 맞춘다. A의 마지막 복원도가 40%였다면 자동 배치 뒤에도 40% 모습이다. B가 나머지를 맞추면 모두 통과한다.
- AC-054 종료 전에 돌아와 접속 중인 A는 자기 조각을 직접 맞춘다. 종료 시점에 부재했던 A가 이후 복귀하거나 종료 이벤트가 재전송되어도 이미 자동 배치한 조각은 중복 생성되거나 다시 배부되지 않는다.

## 9. F-007 — 개인 임시 세션

같은 방을 혼자 시작하면 자신에게 배정된 원조각을 설정에 따라 나눈 뒤 한 판에서 조립한다. 다른 참가자의 입장을 기다릴 필요가 없다.

완료 기준 초안

- AC-024 혼자 시작해도 원조각에 1/4를 설정하면 해당 영역의 조립 조각 4개로 한 판에서 조립할 수 있다.
- AC-025 다른 참가자나 초대 링크 공유를 기다리지 않고 시작할 수 있다.

## 10. F-008 — 원조각 배정·조립 조각 재분할

세션을 만들 때 개설자가 조립용 분할 비율을 정한다. 기본 또는 업로드 이미지에서 나눈 원조각을 그 비율에 맞춰 다시 분할한다. 1/4면 원조각 하나당 네 조각이다. 각 조립 조각은 원조각과의 좌표 관계 및 그 영역에 드러나 있던 모습을 유지한다. 제공할 비율의 종류는 미정이다.

완료 기준 초안

- AC-026 기본 이미지로도 원조각 배정과 조립용 재분할을 진행할 수 있다.
- AC-027 업로드 실패 시 파일을 다시 선택하거나 기본 이미지로 진행할 수 있다. 정상 사진은 분할선 입력 없이 퍼즐로 나뉜다.
- AC-028 진행판에 원조각 6개가 있고 세션 개설 시 분할 비율을 1/4로 정하면 원조각 하나를 맡은 사람은 조립 조각 4개를 받고 공동판에는 총 24개가 생긴다.

## 11. F-009 — 진행판의 개인 복원·타인 최대 블러

집중 중에는 자기 원조각만 개인 복원도대로 보이고 타인의 원조각에는 최대 블러를 덧씌운다. 공동 조립 시작 시 그 덧씌운 블러를 제거한다. 조립 조각마다 집중 종료 시점에 소유자가 복원한 영역만 전원에게 동일하게 보인다. 집중 종료까지 돌아오지 않은 참가자의 조각에는 단절 당시의 복원 상태를 사용한다. 집중 중 계정으로 복귀했다면 복귀 후 진행분을 포함한 최종 상태를 사용한다.

완료 기준 초안

- AC-029 집중 시간에는 내 원조각이 내 복원도에 맞춰 무늬와 윤곽이 드러난다. 동일한 원조각을 다른 참가자가 보았을 때에는 집중 시간이 끝날 때까지 최대 블러다.
- AC-030 집중 시간에 자기 원조각은 이웃과 맞닿는 절단면부터 복원되고 100%에서 해당 원본 영역과 일치한다. 같은 시점에도 팀원 화면에서는 이 원조각의 최대 블러가 유지된다.
- AC-031 한 사람의 연결이 끊기면 성장 경계도 고정된다. 다른 사람의 조각은 계속 진행한다.
- AC-032 같은 세션의 동일한 진행 상태를 다시 그릴 때 불규칙 경계도 튀거나 후퇴하지 않는다. 세션 종료 시 합성 결과를 폐기한다.
- AC-037 A의 복원 상태를 낮은 단계에서 높은 단계로 바꾸면 A 화면만 해당 변화가 보이고 B 화면의 A 원조각은 두 시점 모두 최대 블러다. B 원조각은 반대로 검증한다.
- AC-040 A가 30%, B가 80%에서 집중을 마치면 공동 조립 첫 화면부터 모든 기기가 각각 A의 30%, B의 80% 상태를 사용한다. 1/4 분할이나 조각 이동으로 미복원 영역이 추가 공개되지 않는다.
- AC-038 웹에서 진행판을 보고 만료 후 자기 조립 조각과 방의 공동판으로 진입하는 경로를 검증한다. 웹 카메라 지원은 별도 검토 대상이다.

## 12. F-010 — 계정 가입·로그인

가입·로그인, 닉네임, 계정 관리와 인증에 의존하는 복귀는 모두 후순위다. 이메일 또는 아이디와 비밀번호로 로그인하고 닉네임을 사용한다. 가입 시 받을 식별자와 로그인 시 허용할 입력 조합, 닉네임 중복·변경 규칙은 미정이다.

처리할 기능 후보는 가입·로그아웃, 식별자 중복 확인, 로그인 실패·인증 만료 안내, 비밀번호 재설정이다. 비밀번호는 해시로 저장하고, 닉네임이 같은 사람도 참가 권한은 계정으로 구분하도록 설계한다.

- AC-046 등록된 식별자와 올바른 비밀번호로 로그인하면 본인의 닉네임을 사용할 수 있다. 인증에 실패하면 해당 계정의 복귀 권한을 얻을 수 없다.

## 13. F-011 — 방 찾기·세션 코드 입장

개설한 방의 코드를 공유한다. 비회원도 ‘방 찾기’에서 코드를 입력해 해당 대기방으로 들어간다. 랜덤 참가를 꺼 둔 방도 코드로 입장할 수 있다. 시작 시 명단을 닫는다.

처리할 기능 후보는 코드 발급·충돌 방지·복사, 잘못된 코드와 입장할 수 없는 방의 안내다. 코드 유효기간과 정원은 미정이다.

- AC-047 로그인하지 않은 참가자가 유효한 코드를 입력하면 그 코드의 대기방에 한 번만 입장한다. 잘못된 코드나 종료된 방의 코드로는 입장하지 않는다. 시작된 방에 코드를 입력해 새 참가자로 들어갈 수 없다.

## 14. F-012 — 랜덤 매칭

비회원도 랜덤 매칭을 요청할 수 있다. 개설자가 ‘랜덤 참가 허용’을 켠 기존 대기방 중 빈자리가 있는 방 하나에 무작위로 배정한다. 매칭 조건은 방의 허용 여부 하나다. 시작 여부와 빈자리는 모든 신규 입장에 공통인 확인 사항이다.

처리할 기능 후보는 매칭 대기·취소·성사 안내, 대상이 없을 때의 처리, 중복 요청 방지다. 배정 시점에 랜덤 허용 상태와 입장 가능 여부를 다시 확인한다.

- AC-048 비회원이 랜덤 매칭을 요청하면 허용을 켠 대기방의 빈자리 한 곳에만 배정된다. 허용을 끈 방, 이미 시작된 방, 만석인 방에는 배정되지 않는다. 대상이 없더라도 허용을 끈 방을 사용하지 않는다.
- AC-049 검증 후보. 대기 취소가 먼저 처리되면 이후 방에 배정되지 않는다. 연속 입력으로 두 방에 동시에 배정되지 않는다.

## 15. F-013 — 계정으로 진행 중인 세션 복귀

후순위 계정 기능이다. 참가자가 방 종료 전에 나가거나 연결이 끊긴 뒤 같은 계정으로 앱이나 웹을 다시 열면, 마지막으로 저장된 세션이 열려 있는지 확인하고 그 방의 현재 단계로 자동 이동한다. 코드 재입력이나 방 선택은 필요 없다. 집중 중에는 끊기기 직전의 개인 기록·복원도에서 이어가고, 복귀 이후의 유효한 구간만 반영한다. 공통 종료 시각은 그대로다.

예를 들어 20분 세션에서 8분 시점에 끊겨 11분 시점에 돌아오면, 개인 기록과 복원도는 8분 시점의 값이고 방에는 9분이 남는다. 그 사이 조립이 시작됐다면 자동 완성된 자기 몫을 포함한 현재 공동판을 본다. 방이 이미 종료됐다면 복귀할 세션이 없음을 안내한다.

처리할 기능 후보는 계정별 마지막 세션 참조, 복귀 시 방 상태·참가자 확인, 중복 재접속·여러 기기의 동시 갱신 처리다. 방 종료 시 마지막 세션 참조도 정리한다.

- AC-050 위 20분 예시에서 누락된 3분은 더하지 않는다. 같은 복귀 요청을 두 번 보내도 참가자와 조각은 하나씩만 유지되고 복귀 뒤의 기록도 한 번만 쌓인다.
- AC-051 집중 종료 때 부재했던 사람이 조립 중 같은 계정으로 돌아오면 마지막 세션의 현재 공동판으로 자동 이동한다. 이미 맞춰진 자기 몫과 팀원의 최신 배치가 보인다. 다른 계정은 그 자리에 복귀할 수 없다.
- AC-052 방 종료 후 같은 계정으로 로그인해도 해당 방으로 자동 이동하지 않으며 사진·진행 기록·조립 결과도 다시 열리지 않는다.

## 16. 역할별 연결과 검증 상태

PM은 필터 채택 여부와 분할 비율 선택지를, Design은 집중에서 조립으로 전환되는 화면과 오배치 안내를 검토한다. 구현 담당은 개설 설정, 조각 수, 소유자 이동 권한, 전체 정답 판정, 최종 복원 상태의 일치, 카메라 비공개와 세션 폐기를 검증한다. 비회원 코드 입장·랜덤 매칭과 부재자 조각 자동 배치를 먼저 검증한다. 로그인과 계정 기반 자동 복귀는 후순위다. AC-001부터 AC-054까지는 실행 전이다.

## 17. 변경 기록

v0.11에서 로그인 관련 기능의 우선순위를 낮추고, 비회원 입장·랜덤 참가 허용·마지막 세션 자동 복귀·집중 종료 시 부재자 몫 자동 완성을 반영했다.

v0.10에서 계정 로그인, 코드 입장, 랜덤 매칭, 계정 복귀를 추가 기능으로 등록했다. 집중 중 복귀 전후의 기록과 단절 구간을 구분했다.

v0.9에서 F-006에 오배치 시 직전 위치 복귀와 소유자 재시도를 명시하고, 대기 영역·판 위에서의 복귀 및 마지막 조각 재시도 기준을 반영했다.

v0.8에서 F-002·F-006에 원조각에서 이어지는 이동 권한, 모든 조립 조각의 정답 위치 판정, 미배치·오배치·정답 검증 기준을 반영했다.

v0.7에서 F-001·F-006·F-008·F-009에 개설자의 생성 시 분할 설정과 공동 조립 시작 시 최종 복원 상태 공개를 반영했다.

v0.6에서 필터 후보, 타인 원조각 최대 블러, 원조각 단위 재분할 및 공동판 조립안을 반영했다.

v0.5에서 데모 카메라와 모의 감지, 전체 세트 배부, 독립된 개인판 조립과 개인별 결과 표시를 반영했다.

v0.4에서 F-004·006·008·009를 본인 전용 카메라, 퍼즐 자동 분할, 공동 진행판과 위치 맞히기 게임으로 개정했다.

v0.3에서 같은 기능 ID의 동작과 인수 기준을 고정 타이머·조각 고정·직접 분할·종료 폐기로 개정했다.

v0.2에서 F-007을 개인 모드로 구체화하고 F-008·F-009에 이미지 등록, 인원 분할, 목표 대비 크기 성장과 종료 합성 기준을 추가했다.
