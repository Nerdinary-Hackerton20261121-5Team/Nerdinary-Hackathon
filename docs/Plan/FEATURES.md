# 집중 세션 기능명세 — v0.4

작성 기준일: 2026-11-21. 공동·개인 세션의 고정 타이머, 앱 카메라, 퍼즐 자동 분할, 진행판과 위치 맞히기을 다룬다. 상세 입력·예외·완료 기준은 작성자 제안이며 구현 결과가 아니다. 실제 담당자·검토자·화면 ID·API 경로·기술 스택은 미정이다.

## 1. 기능 목록과 공통 전제

| ID | 기능 | 적용 정책 |
| --- | --- | --- |
| F-001 | 공동 세션 개설·초대 | POL-001, POL-002, POL-011 |
| F-002 | 익명 참가·시작 명단 확정 | POL-002, POL-003, POL-008 |
| F-003 | 고정 타이머 시작·만료 | POL-004, POL-006 |
| F-004 | 경과 시간·본인 전용 카메라 | POL-005, POL-006, POL-012 |
| F-005 | 연결 끊김·조각 고정 | POL-007, POL-008 |
| F-006 | 퍼즐 위치 맞히기·정답 판정·종료 폐기 | POL-009, POL-010, POL-011, POL-014 |
| F-007 | 개인 임시 세션 | POL-001, POL-013, POL-014 |
| F-008 | 퍼즐 이미지 자동 분할·배정 | POL-002, POL-013 |
| F-009 | 전체 퍼즐판·참가자별 복원 | POL-007, POL-009, POL-014 |

앱을 주 이용 환경으로 설계하고 웹에서도 세션을 실행한다. 앱의 얼굴 촬영은 본인에게만 보인다. 카메라 입력을 복원도에 연결하는 기준과 웹 카메라 지원은 Q-002·Q-008에서 결정한다.

## 2. 논리 입력·출력

세션 동안 공통 타이머, 시작 명단, 퍼즐 조각 ID·모양·원래 위치, 참가자별 복원 상태와 단절 시 고정 상태, 위치 선택과 판정이 필요하다. 공동 화면에는 퍼즐 상태만 보낸다. 얼굴 영상은 본인 기기에서만 실시간 처리하고 파일로 녹화하지 않는 방식을 제안한다.

## 3. F-001 — 공동 세션 개설·초대

개설자는 한 방의 목표 시간을 정하고 시작 전까지 초대 링크를 공유한다. 1인과 여러 명이 같은 입구를 쓴다.

완료 기준 초안

- AC-001 방 생성 후 시작 전에는 다른 기기에서 링크로 입장할 수 있다.
- AC-002 생성 요청을 재전송해도 방이 중복 생성되지 않는다.
- AC-003 생성 취소·실패는 타이머를 시작하지 않는다.

## 4. F-002 — 익명 참가·시작 명단 확정

로그인 없이 세션 안에서만 유효한 식별자로 참가한다. 시작 시점의 입장 승인 명단으로 인원과 배정을 고정한다. 시작과 신규 입장이 겹치면 확정 명단을 기준으로 응답한다.

완료 기준 초안

- AC-004 참가자 A와 B의 임시 식별 및 조각은 분리된다.
- AC-005 시작 이후 신규 참가와 만료 링크의 입장은 거절되고 명단·배정이 유지된다.
- AC-006 공유 링크나 다른 참가자 식별자만으로 다른 사람의 조각 상태를 수정할 수 없다.

## 5. F-003 — 고정 타이머 시작·만료

개설자의 시작으로 모든 참가자가 같은 시작·목표 종료 시점을 사용한다. 타이머는 화면 전환, 무응답, 특정 참가자의 이탈 중에도 정해진 속도로 흐른다.

완료 기준 초안

- AC-007 방 개설과 실제 타이머 시작을 구분한다.
- AC-008 화면을 떠나거나 쉬어도 방의 종료 예정 시각은 그대로다.
- AC-009 참가자 A의 단절은 참가자 B의 타이머 진행을 바꾸지 않는다.
- AC-010 시작·만료가 중복 전달돼도 원래 시작·종료 기준을 한 번만 적용한다.

## 6. F-004 — 경과 시간·본인 전용 카메라

방의 시작 시각으로 경과·남은 시간을 구한다. 앱은 카메라 사용 목적을 알린 뒤 사용자가 허용하면 얼굴을 본인 화면에만 표시한다. 웹은 세션 실행을 지원한다. 권한 거부·기기 미지원·일시 미검출 시의 복원 규칙은 미정이다.

완료 기준 초안

- AC-011 목표 20분에 시작 후 8분이면 경과 8분·남은 시간 12분이다.
- AC-012 앱 또는 탭을 바꿔도 같은 방의 경과 시간 계산식을 쓴다.
- AC-013 종이책을 읽거나 우리 화면에서 손을 떼도 실패·딴짓으로 표시하지 않는다.
- AC-014 음수 남은 시간이나 목표를 넘는 타이머 진행률은 표시하지 않는다.
- AC-033 두 참가자가 각자의 앱 카메라를 켜도 상대 화면이나 공동 퍼즐판에 다른 사람의 얼굴이 나타나지 않는다.
- AC-034 카메라가 꺼지거나 얼굴을 찾지 못해도 공통 타이머는 계속 흐른다. 얼굴 미검출과 네트워크 단절을 구별한다.

## 7. F-005 — 연결 끊김·조각 고정

방의 시계와 조각 상태를 따로 관리한다. 연결이 끊긴 참가자의 조각은 단절 당시의 상태로 그 회차 동안 고정한다. 끊김 검출이 늦을 수 있어 마지막으로 확인한 표시 상태를 기준으로 삼는 안을 제안한다.

완료 기준 초안

- AC-015 같은 끊김 통지를 다시 받아도 고정된 조각이 바뀌지 않는다.
- AC-016 끊김 뒤 시간이 더 흘러도 고정된 조각은 그 상태로 합성된다.
- AC-017 단절 원인을 집중 중단으로 표시하지 않는다.
- AC-018 같은 참가자가 재접속하거나 두 탭을 열어도 새 조각을 배정하거나 고정된 조각을 더 키우지 않는다.
- AC-019 기기 시계 변경이나 뒤늦은 이벤트로 이미 고정한 모양을 덮어쓰지 않는다.

## 8. F-006 — 퍼즐 위치 맞히기·정답 판정·종료 폐기

타이머가 만료되면 각 조각의 복원 상태를 확정하고 위치 맞히기로 넘어간다. 참가자가 복원된 조각과 후보 위치를 보고 답을 제출하면 해당 조각의 원래 위치와 대조해 정답 또는 오답을 표시한다. 적게 드러난 조각도 그 상태로 게임에 들어간다. 재시도 횟수·제한시간·팀 승패·1인 게임 규칙은 미정이다.

완료 기준 초안

- AC-020 같은 회차가 끝나면 이전 링크로 사진·결과 또는 시간 기록을 다시 조회할 수 없다.
- AC-021 결과는 해당 세션 범위에서만 열 수 있다.
- AC-022 시간 표시는 경과 시간으로 읽을 수 있고 집중 인증 점수를 붙이지 않는다.
- AC-023 응답 누락이나 단절만으로 사용자에게 실패 판정을 표시하지 않는다.
- AC-035 원래 위치를 선택한 경우와 다른 위치를 선택한 경우의 피드백이 구분된다. 동일한 답을 중복 제출해도 한 시도로 처리하는 안을 검증한다.
- AC-036 복원도가 서로 다른 조각을 게임에 넘기면 타이머 만료 때 드러났던 이미지 정보가 각각 유지된다.

## 9. F-007 — 개인 임시 세션

같은 방에서 1명으로 시작하면 종전의 전체 이미지 복원 흐름을 유지한다. 전체가 한 조각뿐이면 정답 자리가 하나로 자명하므로, 개인 게임의 조각 수 또는 후보 위치를 따로 정해야 한다. Q-007 확정 전까지 1인 위치 맞히기의 규칙은 미정이다.

완료 기준 초안

- AC-024 1명은 전체 이미지를 한 영역으로 배정받고 공통 타이머로 진행한다.
- AC-025 다른 참가자나 초대 링크 공유를 기다리지 않고 시작할 수 있다.

## 10. F-008 — 퍼즐 이미지 자동 분할·배정

기본 이미지를 선택하거나 개설자가 사진 한 장을 올린다. 공동 세션에서는 시작 인원수에 맞춰 코드가 맞물리는 퍼즐 조각을 생성·배정한다. 생성 때 각 조각의 원래 위치를 회차 동안 유지해 마지막 판정에 사용한다.

완료 기준 초안

- AC-026 업로드 없이 기본 이미지로 시작할 수 있고 각 참가자는 자신의 조각을 확인한다.
- AC-027 업로드 실패 시 파일을 다시 선택하거나 기본 이미지로 진행할 수 있다. 정상 사진은 분할선 입력 없이 퍼즐로 나뉜다.
- AC-028 N명의 공동 세션에서 N개 조각이 한 명당 하나씩 배정되고, 정답 위치에 모두 놓으면 겹침이나 누락 없이 같은 원본을 이룬다.

## 11. F-009 — 전체 퍼즐판·참가자별 복원

공부 중 전체 퍼즐판에서 내 조각과 다른 참가자의 조각이 각각 얼마나 복원됐는지 볼 수 있다. 맞닿을 절단면부터 이미지가 드러나며 불규칙한 경계 연출은 권장한다. 판에서 정답 위치가 노출되는 정도와 1인 이미지의 시작점은 Design과 결정한다.

완료 기준 초안

- AC-029 복원도가 높은 조각에는 같은 조각의 낮은 복원 단계에서 보이지 않던 무늬·윤곽이 드러나 게임의 시각 단서가 증가한다.
- AC-030 공동 조각의 첫 복원 위치는 이웃 조각과 붙는 절단면이며 전원 100%에서 원본과 일치한다.
- AC-031 한 사람의 연결이 끊기면 성장 경계도 고정된다. 다른 사람의 조각은 계속 진행한다.
- AC-032 같은 세션의 동일한 진행 상태를 다시 그릴 때 불규칙 경계도 튀거나 후퇴하지 않는다. 세션 종료 시 합성 결과를 폐기한다.
- AC-037 두 명이 같은 전체판을 볼 때 각자 자기 조각을 구분할 수 있고 상대 조각의 복원 변화도 볼 수 있다.
- AC-038 웹에서 방을 열어 진행판을 보고 타이머 만료 후 위치 맞히기에 진입하는 경로를 확인한다. 웹 카메라 동작은 별도 검증 대상이다.

## 12. 역할별 연결과 검증 상태

PM은 카메라·복원도 연결 기준과 게임 규칙을 검토한다. Design은 전체판의 나·팀원 표시와 정답·오답 피드백을, 구현 담당은 카메라 비공개, 자동 분할, 단절 상태 고정과 종료 폐기를 검토한다. 개인별 배정은 미정이며 AC-001부터 AC-038까지는 실행 전이다.

## 13. 변경 기록

v0.4에서 F-004·006·008·009를 본인 전용 카메라, 퍼즐 자동 분할, 공동 진행판과 위치 맞히기 게임으로 개정했다.

v0.3에서 같은 기능 ID의 동작과 인수 기준을 고정 타이머·조각 고정·직접 분할·종료 폐기로 개정했다.

v0.2에서 F-007을 개인 모드로 구체화하고 F-008·F-009에 이미지 등록, 인원 분할, 목표 대비 크기 성장과 종료 합성 기준을 추가했다.
